#  MEDIBOT - AI Health Assistant 🤖  
## **Overview**
MEDIBOT is an **AI-powered medical assistant** built using **Streamlit, LangChain, and Pinecone**. It provides instant **medical insights** based on a **healthcare knowledge base**. 

🔹 **Ask medical queries & get AI-driven answers**  
🔹 **Uses LangChain & Pinecone for efficient retrieval**  
🔹 **Simple, interactive, and user-friendly UI**  

---

## **🚀 Live Demo**
🔗 **[Try MEDIBOT Here](https://medibot-ai-healthassistant.streamlit.app/)**

---

## **🛠️ Tech Stack**
- **Frontend:** Streamlit  
- **Backend:** LangChain, Pinecone  
- **AI Model:** Groq LLM  
- **Deployment:** Streamlit Cloud
